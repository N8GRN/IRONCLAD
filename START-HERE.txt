IRONCLAD CRM
============

This zip is the whole app. Unzip it and you should see index.html
in the same folder as js/, css/, and brand/.

WHAT CHANGED
- Matt signs in as Owner (company owner). Role stays Admin so he
  and Nate have the same privileges.
- Settings → Team: any Admin can add or remove people and change
  names, roles, and “Shown as” labels.
- Settings → Appearance: Light, Dark, or System.
- Materials (sidebar + Settings): admins edit shingle colors, SKUs,
  and prices. Retire a discontinued item or bump a category by %.
  Saved on this device and to Firestore meta/catalog after Firebase
  sign-in. Price changes apply the next time an estimate is saved.
- Production date Reset clears the date (crew stays assigned).
- Estimate gutters/siding: checking the box shows the full
  description in a wide field.

HOSTING
- GitHub Pages: put these files in the repo (or docs/) and enable Pages.
- Firebase Hosting: firebase.json is included. Project ironclad-127a5.

EDITING USERS
You can add people in Settings without touching code. config.js is
only the first-run roster (Nate, Matt, Jon, Jesse, Ethan).
